Comment ça marche

Le format attendu du fichier

  1. Une ligne = une salle. Les colonnes sont repérées par leur nom, dans n'importe quel ordre.
  2. Obligatoires : {% for c in obligatoires %}{{ c }}{% if not forloop.last %}, {% endif %}{% endfor %}. Facultatives : type, equipements, disponible.
  3. capacite : le nombre de places. type : salle de cours (par défaut), amphithéâtre, laboratoire, salle informatique ou atelier. disponible : oui (par défaut) ou non.
  4. Un bâtiment qui n'existe pas encore est créé. Une salle déjà enregistrée (même bâtiment, même nom) est mise à jour.
  5. Une ligne en erreur est signalée sans bloquer les autres.
