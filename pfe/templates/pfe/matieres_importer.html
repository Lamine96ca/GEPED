Comment ça marche

Le format attendu du fichier

  1. Une ligne = une matière. Les colonnes sont repérées par leur nom, dans n'importe quel ordre. Les lignes vides sont ignorées.
  2. Obligatoires : {% for c in obligatoires %}{{ c }}{% if not forloop.last %}, {% endif %}{% endfor %}. Facultatives : code, credit, cycle, promotion, description.
  3. credit vide : 6 crédits par défaut. Sinon, un nombre entier de 1 à 60.
  4. cycle : DUT, Tronc commun, Licence, Ingénieur, Master ou Doctorat. Vide : le cycle du programme est repris.
  5. Le programme, la licence, le semestre (ex. SEMESTRE 1 ou S1, Module 1), la session et la promotion doivent exister, et le semestre doit appartenir à la licence.
  6. Une matière déjà enregistrée (même nom, programme et session) est mise à jour. Une ligne répétée dans le fichier est rejetée.
    7. {% if mes_programmes %}
  7. Votre périmètre : {% for p in mes_programmes %}{{ p.nom }}{% if not forloop.last %}, {% endif %}{% endfor %}. Si une seule ligne porte un autre programme, tout l'import est refusé.
    8. {% else %}
  8. Un chef de programme ne peut importer que les matières de son ou ses programmes : sinon tout son import est refusé.
