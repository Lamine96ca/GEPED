Comment ça marche

Le format attendu du fichier

  1. Une ligne = la soutenance d'un étudiant. Les colonnes sont repérées par leur nom, dans n'importe quel ordre.
  2. Obligatoires : {% for c in obligatoires %}{{ c }}{% if not forloop.last %}, {% endif %}{% endfor %}. L'étudiant, le programme, la session et la promotion doivent exister.
  3. Facultatives : note, note_session, projet, theme, encadreur, chef_departement, maitre_stage, entreprise, president_jury, examinateur, rapporteur, date, heure, salle, statut, cycle (vide : celui du programme). Tout cela peut être complété plus tard dans la gestion des soutenances.
  4. Sur 10. ABS = 0. note_session : on garde la meilleure des deux notes, avec la mention « Session ».
  5. Les lignes qui portent le même projet (même programme, session et promotion) forment un seul projet de soutenance. Sans nom de projet mais avec un thème, un encadreur…, un projet est créé pour l'étudiant seul.
  6. Une soutenance déjà enregistrée est mise à jour (une case vide garde l'ancienne valeur) ; une ligne répétée est ignorée.
  7. Les notes importées sont verrouillées : un nouvel import ne les change plus (seules les informations du projet changent) ; la scolarité les modifie depuis la fiche, avec un motif.{% if mes_programmes %} Votre périmètre : si une ligne concerne un autre programme, tout l'import est refusé.{% endif %}
